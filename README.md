# Sistema de Gerenciamento de Colaboradores

Projeto desenvolvido em Java como parte da disciplina de Desenvolvimento de Software, com foco na aplicação dos conceitos de Programação Orientada a Objetos (POO).

## Sobre o projeto

O sistema tem como objetivo cadastrar colaboradores de diferentes categorias e calcular seus salários, considerando as particularidades de cada tipo de contratação.

## Funcionalidades

- Cadastro de colaboradores padrão.
- Cadastro de colaboradores comissionados.
- Cadastro de colaboradores por produção.
- Cálculo de salário conforme a categoria do colaborador.
- Exibição dos dados dos colaboradores.
- Geração e consulta da folha de pagamento.

## Tecnologias utilizadas

- Java
- Maven
- IntelliJ IDEA
- Git e GitHub

## Conceitos aplicados

- Classes e objetos.
- Encapsulamento.
- Herança.
- Polimorfismo.
- Sobrescrita de métodos.
- Coleções com `ArrayList`.
